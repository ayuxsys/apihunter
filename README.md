## Usage

```console
$ ./apihunter -h
Usage: apihunter [flags]
  -d, --delay int       delay timeout in seconds to wait for while multiple scraping orgs
  -l, --list string     file containing a list of organisations name to hunt api collection for
  -o, --org string      organisation name to hunt api collection for
  -j, --output string   path to the json output file
  -t, --timeout int     timeout in seconds (default 5)
  -v, --verbose         enable verbose logging
```
